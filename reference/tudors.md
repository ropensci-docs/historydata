# Tudor dynasty

Spousal and parent/child relationships among selected members of the
Tudor dynasty, suitable for network analysis.

## Usage

``` r
tudors
```

## Format

A data frame with 35 observations of 3 variables.

## Variables

- `person_1`, `person_2`: The two people in the relationship.

- `relationship`: The type of relationship.

## Examples

``` r
data(tudors)
```
