# Methodist Minutes of the Annual Conferences, 1786–1834

This dataset contains transcriptions of the membership figures from the
annual meeting minutes of the Methodist Episcopal Church in the United
States of America.

## Usage

``` r
methodists
```

## Format

A data frame with 20241 observations of 11 variables.

## References

See the `url` field in each row for a link to the page in the Hathi
Trust from which that row was transcribed.
