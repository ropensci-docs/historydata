# United States Historical City Populations, 1790-2010

A dataset of cities mentioned in the U.S. Census and other data sources.
In general, cities are included once they reach a population of 2,500.
Data is recorded every ten years. See [the dataset's GitHub
page](https://github.com/cestastanford/historical-us-city-populations/)
for details on how the data was gathered.

## Usage

``` r
us_cities_pop
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with
62224 rows and 17 columns.

## References
